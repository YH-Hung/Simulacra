# Simulacra M3 Phase 2 — Admin API Protos & Codegen Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Land the complete `simulacra.admin.v1` contract as a buf module under `api/`, commit its generated Go code under `gen/`, and gate both with a pinned codegen toolchain and CI lint / breaking / sync checks — so Phase 4 can write handlers against a frozen, machine-checked API.

**Architecture:** A buf v2 workspace rooted at the repo (`buf.yaml` listing `api` as its one module) holds five protos, one per admin service. `buf generate` runs two local plugins — `protoc-gen-go` and `protoc-gen-connect-go` — pinned in a nested `tools/` module via Go 1.24 `tool` directives, and writes committed output to `gen/simulacra/admin/v1` (package `adminv1`) and `gen/simulacra/admin/v1/adminv1connect`. A contract test in `internal/admin` asserts the generated surface against an expectation table; CI regenerates and fails on any diff.

**Tech Stack:** Go 1.25, module `github.com/yinghanhung/simulacra`. New tools (in `tools/go.mod`, not the root module): buf v1.72.0, protoc-gen-go v1.36.11, protoc-gen-connect-go v1.20.0. One new root-module dependency: `connectrpc.com/connect` v1.20.0.

**Reference:** Design `docs/superpowers/specs/2026-08-07-m3-p2-admin-api-design.md`; M3 design `docs/superpowers/specs/2026-07-25-m3-test-story-design.md` §5, §13.2. Phase 1 is complete at `65c1380`.

## Global Constraints

- Module path `github.com/yinghanhung/simulacra`; Go 1.25. `gen/` is **public** (import path `github.com/yinghanhung/simulacra/gen/...`), not under `internal/`.
- **buf's dependency graph must never enter the root `go.mod`.** All codegen binaries are pinned in the nested `tools/` module.
- `connectrpc.com/connect` is the **only** new root-module dependency in this phase. `golang.org/x/net` (h2c) arrives in Phase 4.
- **No runtime behavior changes.** No handlers, no `serve --admin`, no core changes. `serve` and `check` are untouched; every existing test keeps passing.
- **`gen/` is generated, never hand-edited.** Every change to it comes from `make generate`.
- Proto package is `simulacra.admin.v1`; every file carries `option go_package = "github.com/yinghanhung/simulacra/gen/simulacra/admin/v1;adminv1";`. The `;adminv1` suffix is what produces package `adminv1` rather than protoc-gen-go's default `v1`.
- buf lint category is **`STANDARD`**. (`DEFAULT` still works but buf v1.72 warns that it is deprecated.)
- Makefile recipe lines are **tabs**, not spaces.

## Pre-verified facts

Every command and file in this plan was executed against buf v1.72.0 before the plan was written. Findings that shape the tasks:

1. `go -C tools mod init` stamps the **local** toolchain version into `go.mod` (e.g. `go 1.26.2`), which would break CI's pinned Go 1.25. Task 1 corrects it with `go mod edit -go=1.25.0`; `go get -tool` then settles it at `go 1.25.10` because a buf dependency requires that patch. CI's `go-version: "1.25"` resolves to the latest 1.25.x, which satisfies it.
2. The five protos below lint clean under `STANDARD` with zero findings.
3. `buf breaking --against '.git#ref=origin/main'` **fails** when the baseline has no `api/` directory: `Failure: Module "path: "."" had no .proto files`. The CI step is therefore guarded by a `git cat-file -e origin/main:api` existence check, which becomes a permanent no-op once `api/` is on `origin/main`. `ref=origin/main` (not `branch=main`) is used because pull-request checkouts have no local `main` branch.
4. Generated symbols are exactly `File_simulacra_admin_v1_<file>_proto`, `adminv1connect.New<Service>Client`, and `adminv1connect.New<Service>Handler`.
5. The contract test in Task 3 compiles and passes against this generated output.

breaking-api: tools

  // Serialized google.protobuf.FileDescriptorSet, applied all-or-nothing.

  repeated ServiceInfo services = 1;
}

  // Fully qualified, e.g. shop.v1.OrderService.
  string name = 1;
  // Descriptor path the service came from.
  string file = 2;
  repeated MethodInfo methods = 3;
}

```proto
syntax = "proto3";

package simulacra.admin.v1;

option go_package = "github.com/yinghanhung/simulacra/gen/simulacra/admin/v1;adminv1";

// StubService creates, lists, and removes stubs. Stub bodies travel as
// documents in the same grammar stub files use; the server parses them with
// the same strict loader, so files and the API can never drift.
service StubService {
  rpc CreateStub(CreateStubRequest) returns (CreateStubResponse);
  rpc ListStubs(ListStubsRequest) returns (ListStubsResponse);
  rpc DeleteStub(DeleteStubRequest) returns (DeleteStubResponse);
  rpc ReplaceAllStubs(ReplaceAllStubsRequest) returns (ReplaceAllStubsResponse);
  rpc ExportStubs(ExportStubsRequest) returns (ExportStubsResponse);
}

// StubOrigin records who owns a stub. File-origin stubs belong to the
// hot-reload watcher; API-origin stubs belong to the client that created them.
enum StubOrigin {
  STUB_ORIGIN_UNSPECIFIED = 0;
  STUB_ORIGIN_FILE = 1;
  STUB_ORIGIN_API = 2;
}

// StubShape is the RPC shape the stub answers.
enum StubShape {
  STUB_SHAPE_UNSPECIFIED = 0;
  STUB_SHAPE_UNARY = 1;
  STUB_SHAPE_SERVER_STREAM = 2;
  STUB_SHAPE_CLIENT_STREAM = 3;
  STUB_SHAPE_BIDI_STREAM = 4;
}

// Stub is the read-only envelope around a stub document.
message Stub {
  string id = 1;
  // Normalized "/pkg.Service/Method".
  string method = 2;
  StubShape shape = 3;
  int32 priority = 4;
  // 0 means unlimited, mirroring the file grammar.
  int32 times = 5;
  StubOrigin origin = 6;
  // "<path>#<index>" for file stubs, "api" for API stubs.
  string source = 7;
  int64 hits = 8;
  // Normalized YAML mapping for this one stub.
  string document = 9;
}

message CreateStubRequest {
  // Exactly one stub as a YAML or JSON mapping. A sequence is INVALID_ARGUMENT.
  string document = 1;
}

message CreateStubResponse {
  Stub stub = 1;
}

message ListStubsRequest {
  // Optional method filter.
  string method = 1;
  // Optional origin filter; STUB_ORIGIN_UNSPECIFIED means all origins.
  StubOrigin origin = 2;
}

message ListStubsResponse {
  repeated Stub stubs = 1;
}

message DeleteStubRequest {
  string id = 1;
}

message DeleteStubResponse {}

message ReplaceAllStubsRequest {
  // Each document is one stub mapping, as in CreateStub.
  repeated string documents = 1;
}

message ReplaceAllStubsResponse {
  repeated Stub stubs = 1;
}

message ExportStubsRequest {}

message ExportStubsResponse {
  // One file-grammar YAML sequence holding every API-origin stub.
  string document = 1;
  int32 stub_count = 2;
}
```

- [ ] **Step 5: Write `api/simulacra/admin/v1/journal.proto`**

```proto
syntax = "proto3";

package simulacra.admin.v1;

import "google/protobuf/any.proto";
import "google/protobuf/duration.proto";
import "google/protobuf/timestamp.proto";

option go_package = "github.com/yinghanhung/simulacra/gen/simulacra/admin/v1;adminv1";

// JournalService reads the recent-call journal.
service JournalService {
  rpc ListCalls(ListCallsRequest) returns (ListCallsResponse);
  rpc WatchCalls(WatchCallsRequest) returns (stream WatchCallsResponse);
  rpc ResetJournal(ResetJournalRequest) returns (ResetJournalResponse);
}

// DecodedMessage carries a data-plane message to clients that do not know its
// type: json for argument capture in any language, wire_bytes for typed
// capture against the client's own generated classes.
message DecodedMessage {
  // Fully-qualified message name.
  string type_name = 1;
  // Canonical protobuf encoding.
  bytes wire_bytes = 2;
  // protojson, rendered against the server registry.
  string json = 3;
}

// MetadataEntry is one gRPC metadata key and all of its values. gRPC metadata
// is multi-valued, which a proto3 map cannot express.
message MetadataEntry {
  string key = 1;
  repeated string values = 2;
}

message CallStatus {
  // gRPC status code; 0 is OK.
  int32 code = 1;
  string message = 2;
  repeated google.protobuf.Any details = 3;
}

// Call is one completed data-plane RPC.
message Call {
  uint64 seq = 1;
  string method = 2;
  repeated MetadataEntry metadata = 3;
  repeated DecodedMessage requests = 4;
  repeated DecodedMessage responses = 5;
  CallStatus status = 6;
  string matched_stub_id = 7;
  google.protobuf.Timestamp start = 8;
  google.protobuf.Duration duration = 9;
}

message ListCallsRequest {
  // Optional method filter.
  string method = 1;
  // 0 means no limit.
  int32 limit = 2;
}

message ListCallsResponse {
  // Newest first.
  repeated Call calls = 1;
}

message WatchCallsRequest {
  // Optional method filter.
  string method = 1;
}

message WatchCallsResponse {
  Call call = 1;
}

message ResetJournalRequest {}

message ResetJournalResponse {}
```

type methodSpec struct {
	Name            string
	ClientStreaming bool
	ServerStreaming bool

// wantSurface is the admin contract as designed. Adding an RPC is a deliberate
// one-line edit here — the right amount of friction for a public API.
var wantSurface = map[string][]methodSpec{
	"simulacra.admin.v1.SchemaService": {
		{Name: "RegisterSchemas"},

func TestGeneratedSurfaceMatchesTheAdminContract(t *testing.T) {
	files := []protoreflect.FileDescriptor{
		adminv1.File_simulacra_admin_v1_schema_proto,
		adminv1.File_simulacra_admin_v1_stub_proto,
		adminv1.File_simulacra_admin_v1_journal_proto,
		adminv1.File_simulacra_admin_v1_verify_proto,
		adminv1.File_simulacra_admin_v1_control_proto,
	}

	got := make(map[string][]methodSpec)
	for _, fd := range files {
		services := fd.Services()
		for i := range services.Len() {
			svc := services.Get(i)
			methods := svc.Methods()
			specs := make([]methodSpec, 0, methods.Len())
			for j := range methods.Len() {
				m := methods.Get(j)
				specs = append(specs, methodSpec{
					Name:            string(m.Name()),
					ClientStreaming: m.IsStreamingClient(),
					ServerStreaming: m.IsStreamingServer(),
				})
			}
			got[string(svc.FullName())] = specs
		}
	}

	for name, want := range wantSurface {
		have, ok := got[name]
		if !ok {
			t.Errorf("service %s is missing from the generated descriptors", name)
			continue
		}
		if !slices.Equal(have, want) {
			t.Errorf("service %s methods = %+v, want %+v", name, have, want)
		}
	}
	for name := range got {
		if _, ok := wantSurface[name]; !ok {
			t.Errorf("unexpected service %s in the generated descriptors", name)
		}
	}
}

// TestTimesFieldsArePresenceTracked guards the correction that made Times a
// plain message instead of a oneof: at_least and at_most must be expressible
// together as a range, and an unset bound must be distinguishable from zero.
func TestTimesFieldsArePresenceTracked(t *testing.T) {
	rng := &adminv1.Times{AtLeast: proto.Int32(1), AtMost: proto.Int32(3)}
	if rng.AtLeast == nil || rng.AtMost == nil {
		t.Fatal("at_least and at_most must be settable together; a oneof would forbid it")
	}
	if rng.Exactly != nil {
		t.Errorf("Exactly = %v, want absent", rng.Exactly)
	}

	zero := &adminv1.Times{AtMost: proto.Int32(0)}
	if zero.AtMost == nil || zero.GetAtMost() != 0 {
